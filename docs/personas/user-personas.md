# User Personas — Workbench

## Overview

Workbench targets three main audiences: **small merchants**, **freelancers**, and **households**. These personas guide product decisions, pricing tiers, and feature prioritization. Workbench is not competing with enterprise tools — it positions itself as a lightweight, affordable, and human-scale project management tool.

---

## Persona 1: Marie — Small Merchant

### Profile

| Attribute | Value |
|---|---|
| Name | Marie Dupont |
| Age | 34 |
| Occupation | Owner of a clothing boutique |
| Location | Lyon, France |
| Tech proficiency | Moderate (uses smartphone, Instagram, basic spreadsheets) |
| Current tools | Notebook, Excel sheets, WhatsApp groups |
| Plan fit | **Pro (3.99 EUR/month)** |

### Background

Marie runs a small clothing boutique in Lyon's city center. She manages inventory, supplier orders, seasonal collections, and two part-time employees. She currently tracks everything in a mix of paper notebooks and Excel sheets, which leads to missed deadlines and stock issues.

### Goals

- Organize seasonal collections planning (spring/summer, fall/winter)
- Track supplier orders and delivery deadlines
- Manage employee task assignments for store operations
- Keep a clear view of what needs to be done this week

### Pain Points

- Paper notebooks are not searchable and easy to lose
- Excel is too rigid — no visual workflow
- Enterprise tools (Jira, Monday.com) are too complex and expensive
- Trello is simpler but still costs 5 EUR/user/month for useful features
- Needs something that "just works" without a learning curve

### How Workbench Helps

- **Board view**: Visual overview of tasks by status (To order, Ordered, Received, Displayed)
- **Backlog**: Quick list of everything that needs doing, filterable and sortable
- **Epics** (Pro): Group tasks by season or collection (e.g., "Collection Été 2026")
- **Export** (Pro): Export task lists to share with her accountant
- **Multiple workspaces** (Pro): One for the boutique, one for a side project (online shop)

### Feature Usage

- Uses Board daily to move tasks across columns
- Creates tickets for each supplier order and task
- Groups seasonal work into Epics
- Exports monthly reports for accounting

### Why Pro Plan

Marie needs 2 workspaces (boutique + online shop), Epics for seasonal planning, and export for her accountant. The free plan's 1 workspace and 50 ticket limits are too restrictive. At 3.99 EUR/month, it's cheaper than a notebook refill.

## Persona 2: Thomas — Freelance Developer

### Profile

| Attribute | Value |
|---|---|
| Name | Thomas Martin |
| Age | 28 |
| Occupation | Freelance web developer |
| Location | Bordeaux, France |
| Tech proficiency | High (full-stack developer, uses CLI, IDEs, multiple SaaS) |
| Current tools | Notion (personal), client-specific Jira/Trello/Asana |
| Plan fit | **Pro (3.99 EUR/month)** |

### Background

Thomas is a freelance developer working with 3-5 clients simultaneously. Each client has their own project management tool, which means Thomas constantly switches contexts. He needs a personal "command center" to track all his active projects, deadlines, and tasks across clients.

### Goals

- Have a single overview of all active client projects
- Track feature requests and bug reports per client project
- Organize work into phases (discovery, development, testing, delivery)
- Manage personal side projects alongside client work

### Pain Points

- Context switching between different client tools (Jira, Trello, Asana)
- No single place to see "what do I need to do today across ALL projects"
- Notion is flexible but too unstructured for project tracking
- Personal Jira/Linear accounts are overkill and expensive for solo use
- Needs subtasks for breaking down features into implementable chunks

### How Workbench Helps

- **Multiple workspaces** (Pro): One per client + one for personal projects
- **Board view**: Kanban for each project's sprint/phase
- **Backlog**: All tasks in a flat list with filters (by status, epic)
- **Epics** (Pro): Group tasks by project phase (MVP, V2, Maintenance)
- **Subtasks** (Pro): Break features into implementation steps
- **Priorities** (Pro): Distinguish urgent client bugs from nice-to-have features

### Feature Usage

- Creates a workspace per client project
- Uses Board for active sprint, Backlog for full feature list
- Epics represent project phases or milestones
- Subtasks decompose user stories into technical tasks
- Priorities help triage across multiple active projects

### Why Pro Plan

Thomas needs 4-5 workspaces, unlimited tickets (active projects generate 50+ tickets easily), Epics and subtasks for structured project management. At 3.99 EUR/month, it's a fraction of what he'd pay for a solo Jira or Linear account.

## Persona 3: Sophie & Marc — Household Organizers

### Profile

| Attribute | Value |
|---|---|
| Name | Sophie & Marc Leroy |
| Age | 40 and 42 |
| Occupation | Teacher (Sophie), Accountant (Marc) |
| Location | Nantes, France |
| Tech proficiency | Basic to moderate (smartphone, email, occasional app use) |
| Current tools | Shared Google Calendar, sticky notes, WhatsApp |
| Plan fit | **Gratuit (Free)** initially, potential upgrade to **Pro** |

### Background

Sophie and Marc are a couple with two children (8 and 12). They're planning a home renovation, organizing family vacations, and trying to keep up with household logistics (school, activities, appointments). They currently use a chaotic mix of WhatsApp messages, fridge sticky notes, and a shared Google Calendar.

### Goals

- Have a shared space to track the home renovation (contractors, materials, deadlines)
- Plan family vacations without endless WhatsApp threads
- Keep a running list of household tasks (repairs, groceries, admin)
- Simple enough that both of them actually use it

### Pain Points

- WhatsApp threads get buried and tasks are lost
- Sticky notes fall off the fridge and can't be shared
- Google Calendar is for dates, not for task tracking
- Trello/Asana feel too "corporate" for family use
- They don't want to pay for something complex — simplicity is key
- Marc forgets what was agreed upon; Sophie wants a written record

### How Workbench Helps

- **Board view**: Visual task board for the renovation (To do, In progress, Done)
- **Backlog**: Running list of household tasks, easy to add new ones
- **3 members** (Free): Sophie, Marc, and optionally a trusted family member
- **Simple columns**: Customize board columns to match their workflow
- **Accessibility**: Works on mobile, easy to add tasks on the go

### Feature Usage

- One shared workspace for "Family Projects"
- Board columns: "À faire", "En cours", "Fait"
- Tasks for renovation steps, vacation checklist items, household chores
- Both add tasks from their phones during the day
- Review the board together on Sunday evening

### Why Free Plan (with Upgrade Path)

The free plan gives them everything they need: 1 workspace, 3 members, Board + Backlog, 50 tickets. The renovation alone might push them over 50 tickets, which would trigger an upgrade to Pro. If they start managing multiple family projects (renovation + vacation + kids activities), Pro at 3.99 EUR/month becomes attractive.

## Pricing Alignment

| Plan | Price | Primary Persona | Use Case |
|---|---|---|---|
| **Gratuit** | 0 EUR | Sophie & Marc | Single project, small household, discovery |
| **Pro** | 3.99 EUR/month | Marie, Thomas | Multiple projects, full features, solo or small team |
| **Équipe** | 6.99 EUR/month | Marie (growth), associations | Collaboration with advanced roles, larger teams |

### Key Pricing Principles

1. **Free must be genuinely useful** — Not a trial. The Leroys should be able to use Workbench for months without paying.
2. **Pro must feel like a bargain** — At 3.99 EUR/month (less than a coffee), unlocking Epics, subtasks, and multiple workspaces is a no-brainer for Marie and Thomas.
3. **Team exists for growth** — When Marie hires a third employee or Thomas brings on a subcontractor, the Team plan offers advanced roles and more members without a per-user price explosion.
4. **Always cheaper than Trello** — Trello Standard costs 5 EUR/user/month. Workbench Pro is 3.99 EUR flat (not per user). This is a competitive advantage for price-sensitive users.

## Targeting Strategy

### Channels

| Channel | Persona | Message |
|---|---|---|
| Instagram / Facebook Ads | Marie | "Gérez votre boutique sans tableur — 3,99 EUR/mois" |
| Dev communities (Reddit, X) | Thomas | "Your personal project command center — cheaper than Jira" |
| Facebook groups (family/home) | Sophie & Marc | "Organisez vos projets familiaux gratuitement" |
| Google Ads (keywords) | All | "gestion projet simple", "alternative trello gratuit" |

### Key Messages Per Persona

- **Marie**: "Tout voir d'un coup d'oeil. Saisons, commandes, tâches — sans prise de tête."
- **Thomas**: "Un seul endroit pour tous tes projets. Plus léger que Jira, plus structuré que Notion."
- **Sophie & Marc**: "Fini les post-it sur le frigo. Organisez vos projets de famille, gratuitement."

### Onboarding Flow

1. **Sign up** (free, no credit card)
2. **Create first workspace** with guided template suggestions:
   - "Boutique / Commerce" (Marie)
   - "Client Projects" (Thomas)
   - "Maison / Famille" (Sophie & Marc)
3. **Pre-configured Board columns** based on template
4. **Prompt to add members** after first 5 tickets
5. **Upgrade prompt** when hitting free plan limits (non-blocking — existing data stays accessible)

## Future Persona Considerations

As Workbench grows, additional personas may emerge:

- **Association Manager** — Small non-profit managing volunteers and events (Team plan)
- **Student** — University student managing group projects (Free plan)
- **Artisan / Craftsman** — Carpenter, plumber managing client jobs (Pro plan)

These would expand the addressable market while staying within the "lightweight, affordable, human-scale" positioning.
