# User Personas — Workbench (Family Edition)

## Overview

Workbench now targets one primary segment: **families managing daily life together**.

The product is intentionally simple:
- One clear default flow (free plan first)
- Two core views (`Board` and `Objectives`)
- Fast onboarding and low cognitive load
- Mobile-first usage for day-to-day updates

These personas are used to guide product decisions, UX copy, and prioritization.

---

## Persona 1: Emma — Family Coordinator

### Profile

| Attribute | Value |
|---|---|
| Name | Emma Laurent |
| Age | 38 |
| Situation | Parent of two children |
| Location | Nantes, France |
| Tech comfort | Medium |
| Devices | Smartphone first, laptop occasionally |
| Current tools | Notes app, WhatsApp, sticky notes |
| Plan fit | Free |

### Context

Emma coordinates many invisible tasks: school logistics, appointments, home admin, shopping, and family projects.

### Goals

- Keep a shared and reliable task board for the household
- Reduce mental load and repeated reminders
- Make priorities visible for everyone
- Keep usage simple enough for daily adoption

### Pain Points

- Information is scattered across messages and notes
- Tasks are forgotten when conversations move on
- Generic tools feel too complex for family routines
- She needs clarity, not configuration

### How Workbench Helps

- `Board` as the daily command center (`To do`, `In progress`, `Done`)
- `Objectives` for medium-term initiatives (moving, renovation, school period)
- Single create flow from the board (no hidden shortcuts)
- Shared visibility across family members

### Success Signal

The family runs a weekly check-in from the board in less than 10 minutes.

## Persona 2: Lucas — Busy Co-Parent

### Profile

| Attribute | Value |
|---|---|
| Name | Lucas Martin |
| Age | 41 |
| Situation | Co-parent with alternating weeks |
| Location | Bordeaux, France |
| Tech comfort | Medium-low |
| Devices | Mobile only most of the time |
| Current tools | Calendar + SMS + memory |
| Plan fit | Free |

### Context

Lucas has little time and needs fast updates while commuting or between meetings.

### Goals

- Know what matters this week without reading long threads
- Update task status in seconds
- Avoid misunderstandings with the co-parent

### Pain Points

- Too many channels, no shared source of truth
- Hard to understand priorities quickly
- Complex UIs are abandoned after a few days

### How Workbench Helps

- Immediate landing on `Board`
- Minimal navigation (only `Board` and `Objectives`)
- Clear ownership and status progression
- Lightweight interactions on mobile

### Success Signal

Lucas can open the app, update one task, and leave in under 30 seconds.

## Product Implications

1. **Free-first by default**: the natural user flow must work fully on the free plan.
2. **Navigation discipline**: keep only the views that create daily value (`Board`, `Objectives`).
3. **Single creation path**: avoid duplicate creation patterns that confuse users.
4. **Mobile speed**: optimize for short sessions and fast status updates.
5. **Clarity over feature count**: each visible action must have obvious value.
